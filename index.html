How the schedule works:

  • Today: Chapter 1 opens on Sunday 15 November 2026 at 00:00 India time, and the menu shows only that chapter.
  • Each Sunday: One new chapter opens at 00:00 India time. Chapter 2 opens on 22 November 2026, Chapter 14 on 14 February 2027, and Chapter 52 on 7 November 2027.
  • Greyed chapters: Chapters that haven’t opened yet appear greyed out with their opening date, for example “Opens 22 Nov 2026”. A link to a closed chapter shows the latest open chapter.

What I tested: I tested the schedule in a headless browser with the clock set to different dates. The right chapter count appeared at each boundary, including the minute before and after a Sunday, before the start date, the day Chapter 52 opens and far in the future. A reader’s wrong phone clock won’t matter once the page is on a website, because the page reads the server’s date. If the server can’t be reached, or the file is opened straight from a computer, it falls back to the device clock.

One limit you should know about: The hiding happens in the reader’s browser, and all 52 chapters are still inside the file. Someone who uses “view page source” could read later chapters early. Most readers won’t, but if you need a strict embargo, use make_release.py (a small script that needs Python 3 installed). Run it with a number, for example python make_release.py 5, to create a file with Chapters 1 to 5 only and no later text inside. In that file the automatic schedule is off, so you would run it and upload a new file each week. A scheduled job on your host could do that for you, and I can help set it up if you want.
